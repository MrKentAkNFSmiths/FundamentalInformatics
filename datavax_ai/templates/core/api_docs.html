Документация по API и интеграциям

Загружайте файлы с компьютера или по публичной URL-ссылке, защищайте их паролем и управляйте личным диском из терминала или ваших программ.

POST /api/upload/ Создать публичный шейр (файл или URL)

Параметры multipart/form-data или JSON: file или url, title, description, password, expires (часы от 1 до 720). Добавьте ?plain=1 чтобы получить ответ одной строкой. 

curl -X POST "{{ base_url }}/api/upload/" \
  -F "file=@example.py" \
  -F "title=Лабораторная работа" \
  -F "password=secret123" \
  -F "expires=48"
GET /api/download/<hash_id>/ Скачать файл по идентификатору

Для защищённых шейров передайте пароль через заголовок X-Share-Password (рекомендуется) или query-параметр ?password=.... 

curl -L -H "X-Share-Password: secret123" "{{ base_url }}/api/download/ab12cd34/" -o example.py
GET DELETE /api/shares/<hash_id>/ Метаданные или удаление шейра владельцем 
curl "{{ base_url }}/api/shares/ab12cd34/"
GET / POST /api/drive/ /api/drive/upload/ Операции с личным облачным диском (с авторизацией) 
curl -u username:password "{{ base_url }}/api/drive/"
