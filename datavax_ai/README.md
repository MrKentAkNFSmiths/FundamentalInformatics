# DataVax v2 (`datavax_ai`)

Переработанная и расширенная версия приложения **DataVax**: личный облачный диск с иерархией папок и сервис мгновенного обмена файлами, текстом и исходным кодом.

## Основные возможности

1. **Личный облачный диск (`/drive/`)**
   - Автоматическое создание корневого каталога (`Мой диск`) и квоты хранилища (500 МБ по умолчанию) при регистрации пользователя.
   - Вложенные папки, хлебные крошки, дерево каталогов в боковой панели, защита от циклических перемещений.
   - Мультизагрузка файлов через Drag & Drop, создание текстовых файлов и кода прямо в папке, предпросмотр и встроенное редактирование кода.
   - Поиск по диску, сортировка, избранное (`★`), переключение сетка/список, экспорт любой папки в `.zip`.
   - Публикация любого файла из диска в один клик с паролем и сроком действия.

2. **Шеринг и редактор кода (`/new/`, `/s/<hash_id>/`)**
   - Три режима создания шейра: редактор кода (`CodeMirror` с подсветкой 14+ языков), загрузка файла и безопасный импорт по URL (с защитой от SSRF).
   - Хешированные пароли доступа (`make_password` / `check_password`), строгий контроль срока действия (HTTP `410 Gone` после истечения), защита raw-файлов от обхода пароля.
   - Счётчики просмотров и скачиваний, лайки, сохранение чужого шейра на свой диск, система жалоб (`/api/shares/<hash_id>/report/`).
   - Команда очистки просроченных шейров: `python manage.py cleanup_expired`.

3. **Профили и REST API (`/profile/<username>/`, `/api-docs/`)**
   - Загрузка верифицированных аватаров (Pillow), редактирование никнейма и bio, статистика и управление своими шейрами.
   - REST API (`/api/upload/`, `/api/download/<hash_id>/`, `/api/shares/<hash_id>/`, `/api/drive/`, `/api/drive/upload/`).

## Архитектура проекта

- `config/` — настройки Django, корневые маршруты, WSGI/ASGI.
- `core/` — модель `FileAsset` (безопасное хранение физических файлов со счетчиком ссылок), SSRF-защищённый загрузчик URL, MIME/языковая детекция, главная страница и документация API.
- `accounts/` — `Profile`, регистрация/авторизация, сигналы провижининга, управление профилем.
- `drive/` — `Folder`, `DriveFile`, сервисы квот, дерева каталогов и ZIP-архивации.
- `shares/` — `Share`, `Like`, `Report`, редактор, просмотр/предпросмотр, команда очистки.
- `api/` — Django REST Framework сериализаторы и эндпоинты.

## Запуск локально

```bash
cd datavax_ai
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements/base.txt

python manage.py migrate
python manage.py runserver
```

## Запуск тестов

```bash
source .venv/bin/activate
python manage.py test
```
